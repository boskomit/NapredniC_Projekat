TESTNI SLUCAJEVI - ASOCIJATIVNA MEMORIJA
========================================

KAKO SE KORISTI
---------------
Pokreni program iz korijenskog foldera projekta:   ./program

Meni:  1 = unos para    2 = pretraga    3 = ispis svih    4 = brisanje    0 = izlaz

Pod "UNOS" je svaki red onako kako ga kucas (poslije svakog reda Enter).
Mozes ga kucati red po red, ili zalijepiti cijeli blok odjednom.
Svaki test pokreces iznova (svaki put novi ./program), da lista krene prazna.
Zadnji red 0 je izlaz iz programa.

Isti test mozes pokrenuti i jednom komandom, npr. test 4:
    printf '1\n1 2 3 4 5\n100\n2\n1 2 3 4 5\n0\n' | ./program

Kratice u ocekivanom izlazu:  [unos kljuca] = program ispise "Unesite kljuc u formatu [x x x x x]"
                              [unos vrijednosti] = program ispise "Unesite vrijednost: "
Navedene su samo bitne poruke, ne cijeli meni.

4. NEISPRAVAN UNOS KLJUCA
=======================================================================
Za SVAKI kljuc iz tabele pokreni poseban test sa ovim unosom (umjesto <KLJUC> upisi kljuc):
        1
        <KLJUC>
        3
        0
OCEKIVANO u svim slucajevima:  Neispravan unos kljuca
                               zatim (ispis) Lista je prazna   -> nista nije ubaceno

    <KLJUC>                          Sta se provjerava
    -----------------------------    ---------------------------------------
    256 0 0 0 0                      preko opsega (max je 255)
    -1 0 0 0 0                       negativan broj
    1 2 3 4                          premalo brojeva
    1 2 3 4 5 6                      previse brojeva
    a b c d e                        slova
    1,2,3,4,5                        zarezi umjesto razmaka
    12345                            jedan broj
    1 2 3 4 5x                       smece na kraju
    99999999999999999999 0 0 0 0     ogroman broj
    (prazan red - samo Enter)        prazan unos

T-pretraga/brisanje sa neispravnim kljucem:
        2                  (ili 4)
        256 0 0 0 0
        0
OCEKIVANO:  Neispravan unos kljuca

T23 Predugacak red u meniju (500 znakova)
    KOMANDA:   printf '%0500d\n3\n0\n' 0 | ./program
    OCEKIVANO: Neispravan unos.  pa  Lista je prazna    (program nastavlja)

T24 Predugacak red kao kljuc
    KOMANDA:   { echo 1; printf '%0500d\n' 0; echo 3; echo 0; } | ./program
    OCEKIVANO: Neispravan unos kljuca  pa  Lista je prazna

T25 Kraj ulaza (EOF) - program mora cisto izaci
    KOMANDE:   printf '' | ./program; echo $?
               printf '1\n' | ./program; echo $?
               printf '1\n1 1 1 1 1\n' | ./program; echo $?
    OCEKIVANO: program zavrsi sam (bez petlje i bez pada), izlazni kod 0
    (interaktivno isto dobijes sa Ctrl+D umjesto unosa)

T26 Zadnji red bez novog reda
    KOMANDA:   printf '1\n5 5 5 5 5\n7\n3' | ./program
    OCEKIVANO: Kljuc: (5 5 5 5 5) -> Vrijednost: 7

T27 Veliki broj parova (3000)
    KOMANDE:
        for i in $(seq 0 2999); do printf '1\n%d %d 0 0 0\n%d\n' $((i/256)) $((i%256)) $i; done > stres.txt
        printf '3\n0\n' >> stres.txt
        ./program < stres.txt | grep -c 'Kljuc: ('
    OCEKIVANO: 3000
    Provjera brzine (pretraga je O(n)):   time ./program < stres.txt > /dev/null

T28 Brisanje svih 3000 parova
    KOMANDE:
        for i in $(seq 0 2999); do printf '4\n%d %d 0 0 0\n' $((i/256)) $((i%256)); done > brisi.txt
        cat stres.txt | head -n -2 > svi.txt
        cat brisi.txt >> svi.txt
        printf '3\n0\n' >> svi.txt
        ./program < svi.txt | tail -n 3
    OCEKIVANO: pri kraju ispisa stoji  Lista je prazna

=======================================================================
9. PROVJERA MEMORIJE
=======================================================================
Ovi testovi ne gledaju izlaz programa, nego da li ima curenja memorije
i nedefinisanog ponasanja. Pokreni T6, T10, T27 i T28 ovako:

    Sa valgrind-om (obican program, bez sanitizera):
        make clean && make
        valgrind --leak-check=full ./program < stres.txt
    OCEKIVANO: "All heap blocks were freed -- no leaks are possible"

    Sa sanitizerima (ako su instalirani libasan i libubsan):
        make sanitize
        ./program < stres.txt
    OCEKIVANO: nema nikakvih ispisa  ERROR: AddressSanitizer / runtime error

Vazno: program mora osloboditi memoriju i kad se izadje bez brisanja parova
(izlaz opcijom 0 poziva asmem_destroy), i kad je lista prazna.
